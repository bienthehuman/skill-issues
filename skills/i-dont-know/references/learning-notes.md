# Learning Notes

Use these fields as a content guide, not mandatory headings. Simple questions
receive simple explanations; combine fields into conversational prose. Read this
template before drafting. When consuming artifacts, put the required envelope
before the notes: `Upstream: <names> | Re-derived: <claims and actual checks>`.
Name unavailable checks and their limits; omit the envelope without upstreams.

## Direct answer

Answer the user's central question immediately. If knowledge level is unknown,
follow with one brief inferred starting-level line; do not begin with a survey.

## First-principles explanation

Explain the mechanism from the relevant foundations, skipping what the user
already demonstrates. Scale depth to the concept and available context.

## Necessary terminology

Define new technical terms at first use within the explanation. This field is
not a glossary to front-load before the answer or an invitation to add jargon.

## Practical example, where appropriate

Use a concrete example or analogy only when helpful; map it back to the mechanism.
Match supplied stack/version context. Label illustrative code or predicted output
so it cannot be mistaken for inspected code or observed execution.

## Limits of the mental model

Identify the simplification and where it breaks, including practical consequences
and context/version dependencies. Separate technical facts from teaching models
and claims about a specific system. Support evidential claims with actual sources
or checks; use `inferred`, `assumed`, `unknown` as applicable. Revisit load-bearing
inferences/assumptions, and surface unresolved relied-on assumptions as brief open
questions here. State which claims need independent checking before downstream
engineering use; unavailable evidence does not become verification.

## Recommended next learning topic

Name one useful next concept and explain the connection briefly.

## Comprehension check — only when requested

Present a question/scenario and wait for the user's prediction. Reveal the result
and reasoning only afterward, in a subsequent turn; correct misunderstandings
without unnecessary praise. If a prediction is already supplied, explain it now.
Do not append a quiz to an ordinary explanation or force these headings into it.
